## Guard do Hermes crasha ao executar binário ELF — 13:45
`lifecycle_guard` tenta ler qualquer comando como script e quebra com "embedded null byte" ao executar binários (ex: `./cli-proxy-api --version`), mesmo via `bash -c`. Não é permissão — é bug do guard. Não insistir nem repetir: deixar os arquivos prontos e entregar o comando pro Giovani rodar no terminal dele. Qualquer binário novo baixado na VPS vai passar por isso.

## OAuth de CLI em servidor remoto: redirect pra localhost não abre no celular — 14:10
`cli-proxy-api --claude-login` redireciona o navegador pra `localhost:54545/callback?code=...`. Acessando a VPS via SSH do celular, esse link aponta pro próprio celular e não carrega. Solução: túnel `ssh -L 54545:localhost:54545 root@IP` antes de rodar o login. Giovani reportou que o fluxo acabou funcionando mesmo assim (colou/abriu o link de alguma forma) — mas o túnel é o caminho confiável. Vale pra qualquer CLI com login OAuth (Claude Code, Codex, etc.).
