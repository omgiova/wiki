## Pitfall: `hermes config set custom_providers <json>` grava STRING, não lista — 12:08
`hermes config set` com valor JSON grava string literal no YAML, quebrando a lista esperada (`isinstance(custom_providers, list)` falha → provider aparece como "anthropic" com 0 models). Caminhos corretos: chamar `_save_custom_provider(base_url=..., name=..., api_mode=...)` de hermes_cli.main, ou `hermes config set custom_providers.0.<campo> <valor>` (por índice, preserva lista). Verificar sempre o YAML resultante.
