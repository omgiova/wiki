## Rich: adapter envia só via campo markdown — HTML-only quebra — 08:08
O adapter Hermes monta o payload sendRichMessage SEMPRE com `{"markdown": content}`, nunca `html`. Constructs HTML-only chegam quebrados em texto cru: `<figure>`/`<figcaption>`, `<tg-map>`, `<tg-collage>`, `<tg-slideshow>`, `<aside>`, `<footer>`, âncoras `<a name>` + links `#internos`, `![time](tg://time?...)` — e `_rich_normalize_linebreaks` ainda corrompe blocos HTML multilinha. Validado na prática 2026-08-17 (rodada com esses constructs veio quebrada; rodada só com markdown renderizou 100%). Aplicar: em mensagens ricas, usar apenas constructs markdown (headings, tabelas pipe, task lists, blockquotes aninhados, `<details>`, math, footnotes, `<u>/<sub>/<sup>`).
