## Plugins web do Hermes são opt-in — registry vazio = erro "no registered web search provider" — 09:24
Causa raiz de web_search/web_extract falhando: os 9 backends (firecrawl, ddgs, exa, parallel, tavily, keenable, searxng, brave-free, xai) só carregam se estiverem em `plugins.enabled` do config.yaml — antes estavam ausentes, então `get_provider('firecrawl')` retornava None. Fix: `hermes plugins enable web/<vendor>`. Só tem efeito na próxima sessão ("Takes effect on next session"). Para diagnosticar, rodar com o python da venv do Hermes (`/root/.hermes/venv/bin/python`), não com o python do sistema (que não tem as deps/httpx).

## Agente não edita config.yaml do Hermes — usar comandos autorizados — 09:24
`patch`/`write_file` recusam `/root/.hermes/config.yaml` ("Refusing to write to Hermes config file"). Caminhos que funcionam: `hermes config set <chave> <valor>` (ex: `hermes config set browser.cloud_provider browser-use`, avisa se a chave não é reconhecida mas grava) e `hermes plugins enable <plugin>` (atualiza a lista `plugins.enabled`). Para config de browser/web, mexer via esses comandos, nunca na mão.

## Browser Use CLI 3.0 = binário `browser-harness`, não o pacote PyPI `browser-use` — 09:24
A doc do Hermes chama de "CLI 3.0" o `browser-harness` (`uv tool install --python 3.12 --upgrade --force browser-harness`). `uvx browser-use` resolve um harness distinto (0.1.9 nem existe no PyPI do browser-use) — não confundir; o doctor oficial é `browser-harness --doctor`. O `browser_exec` (Browser Use mode) exige Chrome/Chromium com remote debugging via CDP; Chromium snap trava o daemon (`daemon alive FAIL: CDP endpoint not reachable`) — usar Chrome não-snap ou apontar `BU_CDP_URL` para uma instância já rodando (ex: `http://127.0.0.1:9222`). Navegação local não precisa de conta/API key.

## ocg-usage é bloqueado dentro do gateway — rodar via SSH — 09:24
`/root/scripts/ocg-usage 15m` é barrado pelo guard de segurança quando executado dentro do processo do gateway (falso positivo: o guard lê o script referenciado e vê termos de restart/stop). Regra: não reintentar variantes nem contornar — rodar fora do gateway via SSH (`ssh root@<host> '/root/scripts/ocg-usage 15m'`) e interpretar o output. Janelas válidas: 15m|30m|1h|3h|6h|12h|1d|3d|1w, flags `--json`/`--top N`.
